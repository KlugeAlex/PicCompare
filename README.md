# PicCompare 图像比对

PicCompare 是用 C++ 编写的 Windows 桌面图像比对工具，支持同时查看 1–8 张图、双屏联动、像素级放大、ROI 测量和双图差值。

## 下载与快速开始

1. 在 [GitHub Releases](../../releases/latest) 下载 `PicCompare-Windows-x64.zip`。解压后双击 `PicCompare.exe`，适用于 Windows 10 / 11 x64，无需安装。
2. 点击 **＋ 添加文件夹**，或从资源管理器拖入文件夹。也可在左侧目录树里双击文件夹，或将它拖到加号上。
3. 选中 1–8 张图片，按 **空格**或点击 **对比**。对比页按 **K** 打开快捷键面板。

关闭软件时会记住浏览路径和已添加的文件夹。重新启动后使用默认缩放和位置。

## 选图与翻页

每列对应一个文件夹，每张图用一条紧凑横条显示缩略图、文件名和大小。可统一按自然文件名或文件修改时间排序。添加目录时默认选中该列第一张。点击缩略图选单张，点击行号选整行，点击列头 **全选** 选整列。按住 Ctrl 可增选，或取消已全部选中的一组。选中超过八张时，可以从所选图片中挑出连续八张开始对比。

在浏览页按空格进入对比。对比标题使用“父文件夹 / 文件名”，便于区分同名图。进入后空格前进一组，B 后退一组。每个窗格沿自己的目录排序移动一张，保留初始行号差。例如左列第 1 张和右列第 3 张会一起切到左列第 2 张和右列第 4 张。任一窗格到达边界时，整组停在当前位置。

预览图片支持右键移除，也可按 Delete 处理已选图片。**移出本次预览**后可用 **重新载入** 恢复。**永久删除**会打开第二次确认窗口，默认焦点在取消。按 Enter 或 Esc 可取消永久删除。

## 对比快捷键

| 操作 | 用途 |
|---|---|
| 左键拖动 / Ctrl + 左键拖动 | 联动平移 / 单图平移。联动时叠加到已有的单图偏移。 |
| 滚轮 / 1 | 各窗格以鼠标在当前窗格的同一相对位置为锚联动缩放 / 100% 实际像素。 |
| 按住 S + 左键拖动 | 创建跨图同步的 ROI。松开后保留新框并替换旧框，每张图只保留一个。 |
| Shift + 左键拖动 ROI | 拖框内移动，拖边或角调整大小。 |
| Ctrl + Shift + 左键拖动 ROI | 只移动或调整当前图片的 ROI。 |
| 右键点击 ROI | 删除整组同步的 ROI。 |
| O / I / U | 顺时针旋转 90° / 左右镜像 / 上下翻转。加 Ctrl 仅作用于当前窗格。 |
| 按住 C | 恰好两张图时，右图临时覆盖左窗格。松开恢复。 |
| D | 恰好两张图时，开关右侧差值。右侧滚轮调增益，Shift + 滚轮缩放。 |
| A / H / P | 叠加信息 / RGB 直方图 / 联动探针。 |
| F | 在扩展屏上分屏，或合并屏幕。超过两张时可用 − / ＋ 调整第一屏的张数。 |
| R | 恢复适应窗格，复位平移、缩放、覆盖和差值。 |
| K / Esc | 快捷键面板 / 返回浏览或关闭弹窗。 |

## 像素与测量口径

- 支持 JPEG、PNG、BMP、TIFF、WebP、GIF、ICO。整数图像支持常见 8 位样本及 PNG/TIFF 的 16 位灰度、RGB 和 RGBA。多页或动画文件显示第一帧。浮点 TIFF 不在此版范围内。
- 对比画布按宽高约束等比例适应，每个显示像素取单个源像素。原位深样本用于取值、统计和差值。不同尺寸时，ROI 和探针用旋转、翻转后的图像相对坐标联动。
- ROI 根据像素中心是否在框内取样。全透明像素跳过。RGB 和亮度标准差使用对应位深的 DN。Lab 按 sRGB/D65 换算，HSV 的 H 用饱和度加权的环形平均。此版按解码 RGB 样本计算，色彩配置文件转换不在测量范围内。
- 空域 σY 是单张 ROI 内的亮度样本标准差，包含该区域的纹理和渐变。可用各图对应的平坦区域比较。
- 差值按旋转、翻转后的左上角整数坐标对齐，仅使用共同覆盖的像素。映射为 128 + 增益 × (右 − 左)，亮度差以 8 位等效尺度表示并保留内部高位深精度，显示裁剪到 0–255。平移和缩放只影响视野。

## 重新编译

安装 Visual Studio 的 **使用 C++ 的桌面开发**工作负载及 Windows SDK。在项目根目录打开 PowerShell，执行以下命令。

```powershell
.\build.cmd
```

生成的 `PicCompare.exe` 位于项目根目录。首次构建需要联网下载并校验 Google 提供的 libwebp x64 包。exe 静态链接 libwebp 和 C++ 运行库。源码位于 `src/`，包括 C++、图标和应用清单。

安装 Python 3 后运行 `.\verify.cmd`，可验证 16 位 PNG/TIFF 取值、ROI 统计和编辑、旋转翻转、带符号差值和窗格锚点缩放。

WebP 解码使用 libwebp。相关条款见 [WebP-LICENSE.txt](WebP-LICENSE.txt) 和 [WebP-PATENTS.txt](WebP-PATENTS.txt)。
